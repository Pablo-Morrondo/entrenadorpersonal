# Entrenador Personal – PWA v0.1

Primera versión del dashboard móvil.

## Incluye
- Check-in diario rápido
- Estado semáforo del Aquiles
- Dolor, tirantez, rigidez, hinchazón y respuesta a 24 h
- Registro de fisioterapia
- Sesión diaria editable
- Registro de entrenamientos
- Peso opcional
- Calendario para viajes, fisio, descanso e imprevistos
- Almacenamiento local en el dispositivo

## Importante
Los datos se guardan en `localStorage` del navegador. En esta versión no existe todavía sincronización entre dispositivos ni copia de seguridad en nube.

## Publicación
Sube todos estos archivos a un hosting estático con HTTPS (GitHub Pages, Netlify, Vercel, etc.). Abre la URL publicada en Safari del iPhone y usa "Añadir a pantalla de inicio" / "Abrir como app web".
